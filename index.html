配信準備アシスト

配信の種類を選ぶだけで、配信前の準備をそろえる Windows 向けのデスクトップ アプリです。

できること

  • 配信の種類ごとに、立ち上げるアプリ・OBS のシーンコレクション・概要欄のテンプレート・使用素材のクレジットを登録しておき、まとめて準備する
  • OBS の設定(マイク・録画・シーン・ビットレート)を配信前に確かめる
  • 概要欄の文をコピーする
  • YouTube の配信枠(予約枠)を、配信の種類ごとの設定から立てる(任意。利用者が自分の Google Cloud のクライアントでつなぐ)

YouTube との連携

YouTube との連携は任意です。つなぐと、アプリは YouTube API サービスを使って、利用者のチャンネルに配信枠を作ります。

連携には、利用者が自分で作った Google Cloud の OAuth クライアントを使います。アプリの提供元のサーバーは通りません。

取り扱う情報は プライバシー ポリシー に書いています。
