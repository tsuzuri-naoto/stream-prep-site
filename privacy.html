配信準備アシスト / 制定日: 2026 年 10 月 17 日

基本の考え方

配信準備アシスト(以下「このアプリ」)は、利用者の PC の中だけで動くデスクトップ アプリです。提供元はサーバーを持たず、利用者の情報を受け取ったり集めたりしません。

このアプリが読む PC の中のファイル(OBS の設定・素材のファイルなど)と、利用者が登録した内容は、利用者の PC の中に保存されます。提供元や第三者へは送りません。

YouTube API サービスの利用

このアプリは、YouTube との連携に YouTube API サービスを使います。連携は任意で、利用者が「Google でログイン」を押して許可したときだけ有効になります。

YouTube との連携を使う利用者は、YouTube 利用規約 に同意したものとみなされます。Google による情報の扱いは Google プライバシー ポリシー を参照してください。

許可を求める権限は「YouTube アカウントの管理」の 1 つです。この権限で、次のことだけを行います。

  • つないだチャンネルの名前を読み、画面に出す
  • ストリームキーの一覧を、名前だけ読む(キーそのものは受け取りません)
  • 動画のカテゴリの一覧を読む
  • 利用者が「配信枠を立てる」を押したときに、配信枠を作り、選んだストリームキーにつなぎ、タイトル・概要欄・タグ・カテゴリを入れる

保存する情報と保存場所

  • クライアント ID・クライアント シークレット(利用者が入力したもの)
  • リフレッシュトークン(ログインを続けるための鍵)
  • つないだチャンネルの名前
  • 立てた配信枠の記録(動画 ID・タイトル・開始日時・公開設定)

これらは利用者の PC の中にだけ保存します。クライアント シークレットとリフレッシュトークンは、Windows の仕組みで暗号化して保存します。暗号化が使えない PC ではファイルに書かず、アプリを閉じると消えます。

これらの情報を送る先は、Google(YouTube)だけです。広告・アクセス解析・第三者への提供には使いません。

Google API サービスから受け取った情報の扱いは、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。

連携の解除と情報の削除

  • アプリの「連携を解除」を押すと、Google にリフレッシュトークンの取り消しを送り、PC に保存したリフレッシュトークンとチャンネル名を消します。
  • Google アカウントの サードパーティ製のアプリとサービス からも、いつでも許可を取り消せます。
  • アプリをアンインストールしたあとに残る保存データは、利用者の PC の %APPDATA%\stream-prep フォルダを消すと削除できます。
